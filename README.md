# GARAJE SHOPPING

Marketplace independiente para descubrir y comprar muebles, ropa vintage, artículos únicos, coleccionables, decoración, iluminación y herramientas.

## Experiencia de compra

Los clientes podrán explorar el catálogo, añadir productos al carrito y confirmar pedidos sin crear una cuenta. El proceso recopilará sus datos de contacto y dirección de entrega, con opciones de pago contra entrega y electrónico.

## Independencia del proyecto

GARAJE SHOPPING mantiene su propio repositorio, aplicación, catálogo, carrito y configuración. No forma parte de AUTO AIRE VÁSQUEZ ni modifica ese proyecto.
